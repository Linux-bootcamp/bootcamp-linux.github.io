Sujet 1 : Le Système de Fichiers Linux

Qu'est-ce que le système de fichiers ?

En bref : c'est la structure hiérarchique qui organise tous les fichiers sur votre système.

  • Hiérarchie Unique : Tout commence à la racine, symbolisée par /. Il n'y a pas de C:\ ou D:\.
  • "Tout est un fichier" : Une philosophie clé de Linux. Les documents, répertoires, disques durs, et même les périphériques sont représentés comme des fichiers.

La Hiérarchie des Fichiers (FHS)

Le Filesystem Hierarchy Standard (FHS) définit les répertoires principaux et leur utilité.

[Image de la hiérarchie du système de fichiers Linux]

La Hiérarchie des Fichiers (FHS) - Partie 1

  • / (Root) : Le point de départ de toute la structure.
  • /bin (Binaries) : Programmes essentiels pour tous les utilisateurs (ex: ls, cp, cat).
  • /sbin (System Binaries) : Programmes essentiels pour l'administration (ex: fdisk, reboot).
  • /etc (Etcetera) : Contient tous les fichiers de configuration du système.
  • /home (Maison) : Les dossiers personnels des utilisateurs (ex: /home/alice).
  • /root : Le dossier personnel de l'utilisateur root (l'administrateur).

La Hiérarchie des Fichiers (FHS) - Partie 2

  • /var (Variables) : Fichiers dont le contenu change souvent : logs (/var/log), caches, e-mails...
  • /tmp (Temporary) : Fichiers temporaires. Souvent vidé au redémarrage.
  • /usr (User System Resources) : La majorité des logiciels et utilitaires installés (/usr/bin, /usr/lib).
  • /dev (Devices) : Fichiers représentant les périphériques (ex: /dev/sda1 pour un disque).
  • /mnt & /media : Points de montage pour les périphériques amovibles (clés USB).

Sujet 2 : Les Utilisateurs et les Groupes

Les Utilisateurs

Linux est un système multi-utilisateurs. Chaque utilisateur est isolé pour des raisons de sécurité.

  • Pourquoi ? Pour contrôler qui a le droit de faire quoi. Un utilisateur ne peut pas modifier les fichiers d'un autre (sauf permission).

Types d'utilisateurs

  1. root (Super-utilisateur) :
    • L'administrateur suprême. A tous les droits sur le système.
    • Son UID (User ID) est 0.
    • On utilise la commande sudo pour exécuter des actions en tant que root de manière temporaire.
  2. Utilisateurs Standards :
    • Ceux que vous créez pour un usage quotidien (ex: alice).
    • Leurs droits sont limités à leur dossier /home.
  3. Utilisateurs Système :
    • Comptes créés pour faire fonctionner des services (ex: www-data).
    • Ils n'ont pas de dossier /home et ne sont pas faits pour se connecter.

Les Groupes

Un groupe est simplement un ensemble d'utilisateurs.

  • Pourquoi ? Pour gérer les permissions de manière efficace.
  • Exemple :

    Au lieu de donner la permission d'accéder à un dossier "Projet" à Alice, Bob, et Carol individuellement...

    ... on crée un groupe dev, on y ajoute Alice, Bob et Carol, et on donne la permission au groupe dev.

Groupes & Fichiers Clés

Groupe Primaire vs Secondaire

  • Primaire : Le groupe par défaut de l'utilisateur (souvent du même nom). Les fichiers créés appartiendront à ce groupe.
  • Secondaire : Groupes additionnels auxquels l'utilisateur appartient (ex: sudo, dev, audio).

Fichiers de Configuration Clés

  • /etc/passwd : Liste des utilisateurs, UID, GID, /home, shell. *Sans* les mots de passe.
  • /etc/shadow : Contient les mots de passe chiffrés. Seul root peut lire ce fichier.
  • /etc/group : Liste des groupes et de leurs membres.

Commandes Utiles

whoami

Affiche qui vous êtes.

id

Montre votre UID, GID et vos groupes.

sudo [commande]

Exécute une commande en tant que root.

useradd / adduser

Ajoute un utilisateur.

usermod

Modifie un utilisateur (ex: l'ajouter à un groupe).

userdel

Supprime un utilisateur.

passwd

Change votre mot de passe.
